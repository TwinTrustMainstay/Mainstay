# Documentation Archive

> **Last updated:** 2026-10-16 · **Doc version:** 0.1.0

This directory holds read-only snapshots of documentation from earlier releases. See [DOC_MAINTENANCE.md](../DOC_MAINTENANCE.md) for when and how to archive a doc.

## Index

| Release | Snapshots | Notes |
|---------|-----------|-------|
| 0.1.0 | _none yet_ | First release with versioned docs. Snapshots start with the next release. |

Snapshots are stored as `archive/<release>/<doc-name>.md`. Do not edit them. To fix a mistake in a snapshot, fix the live doc and note the correction in the live doc's version history.
