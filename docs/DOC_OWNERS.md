# Documentation Owners

> **Last updated:** 2026-10-16 · **Doc version:** 0.1.0

Each documentation area has one owner who reviews changes and keeps the area current. See [DOC_MAINTENANCE.md](DOC_MAINTENANCE.md#5-documentation-owners) for the policy.

| Area | Docs | Owner |
|------|------|-------|
| Asset Registry contract | `asset-lifecycle.md`, `asset-search.md`, `secure-asset-data` (`SECURE_ASSET_DATA.md`) | Unassigned |
| Engineer Registry contract | `credentialing.md`, `engineer-operations.md`, `engineer-training.md` | Unassigned |
| Lifecycle contract | `architecture.md`, `contract-interaction-sequences.md`, `maintenance-record-versioning.md`, `event-reference.md` | Unassigned |
| Lending | `collateral-lien-guide.md`, `lender-integration-guide.md` | Unassigned |
| Scoring | `collateral-scoring.md`, `collateral-scoring-formula.md`, `scoring-algorithm-deep-dive.md` | Unassigned |
| Errors and events | `error-reference.md`, `event-reference.md` | Unassigned |
| Upgrades and deployment | `upgrade-testing.md`, `deployment-runbook.md`, `multi-region-deployment-guide.md` | Unassigned |
| Operations and incident response | `operations-runbook.md`, `operator-runbook-emergency-pause.md`, `disaster-recovery-plan.md`, `backup-procedures.md`, `monitoring-guide.md` | Unassigned |
| Security and privacy | `threat-model.md`, `audit-report.md`, `access-control.md`, `privacy.md` | Unassigned |
| Integrations | `EVENT_INDEXER.md`, `webhook-integrations.md`, `rate-limiting.md`, `api-performance.md` | Unassigned |
| Onboarding and terminology | `ONBOARDING.md`, `GLOSSARY.md`, `roadmap.md` | Unassigned |

Owners are unassigned until a maintainer records a name here. A release should not ship with unassigned areas that changed in that release.
